# Digital_Relay_Based_Protection_and_Fault-_Monitoring_for_EVs
# Smart EV Charger Protection System

## Overview
A MATLAB/Simulink-based project for smart EV fast charging with digital relay-based protection and fault monitoring.

## Objectives
- Simulate EV battery charging.
- Monitor charging voltage and current.
- Detect overvoltage, undervoltage, and overcurrent conditions.
- Implement relay-based fault identification and tripping logic.

## Tools Used
- MATLAB
- Simulink

## System Features
- Battery State of Charge (SOC) monitoring
- Voltage and current monitoring
- Fault detection and classification
- Relay trip and reset logic

## Test Scenarios
1. Normal charging
2. Overvoltage
3. Undervoltage
4. Overcurrent

## Project Files
- Simulink model: `Smart_EV_Charger_Protection.slx`
- `docs/`: Block diagram and flowchart
